#Training and Placement Cell Management System

This program manages student information and determines job eligibility based on specific criteria. It supports the following features:

Input and store student details: name, ID, age, CGPA, backlog status, and course skills.
Evaluate eligibility for jobs at Microsoft or NASA based on provided conditions.
Save student records to a file (saved.txt) for future reference.
Display all saved student information and job results.

How It Works

The user inputs student details and skill preferences.
The program checks eligibility for:
Microsoft: Requires specific course skills (Data Science, Cloud Computing, Cybersecurity, IoT).
NASA: Requires knowledge in Heat Transfer, Thermodynamics, and Energy Systems.
The results are displayed and stored in a file.
Users can add multiple student entries and view the saved list.

Usage

Run the program and follow the prompts to manage student records and job placements.
