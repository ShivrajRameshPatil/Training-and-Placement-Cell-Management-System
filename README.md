# Training and Placement Cell Management System

This program is designed to manage student information and determine job eligibility based on specific criteria. It supports the following features:

## Features

- Input and store student details including:
  - Name
  - ID
  - Age
  - CGPA
  - Backlog status
  - Course skills
- Evaluate eligibility for job opportunities at:
  - **Microsoft**
  - **NASA**
- Save student records to a file (`saved.txt`) for future reference.
- Display all saved student information and job eligibility results.

## How It Works

1. **Student Details Input**:
   - The user inputs student information such as name, ID, age, CGPA, backlog status, and course skills.
   
2. **Eligibility Evaluation**:
   - **Microsoft**: Requires specific course skills such as Data Science, Cloud Computing, Cybersecurity, or IoT.
   - **NASA**: Requires knowledge in Heat Transfer, Thermodynamics, and Energy Systems.

3. **Display and Save Results**:
   - The program evaluates the student's eligibility for both Microsoft and NASA and displays the results.
   - The student records, along with job eligibility results, are saved to a file named `saved.txt`.

4. **Multiple Student Entries**:
   - Users can add multiple student records.
   - All saved student records and their job eligibility results can be viewed at any time.

## Usage

1. Clone or download the repository to your local machine.
   
2. Run the program by executing the appropriate command in your terminal or IDE.
   
3. Follow the on-screen prompts to input student details and evaluate their job eligibility.

4. After entering student records, the eligibility results will be displayed. The student records will also be saved in `saved.txt` for future reference.

5. You can view all saved records by reading the `saved.txt` file.
